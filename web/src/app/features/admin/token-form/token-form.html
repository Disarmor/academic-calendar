Вход для старосты

Как получить токен
  1. Откройте создание fine-grained токена на GitHub.
  2. Repository access: Only select repositories → academic-calendar.
  3. Permissions → Add permissions → Contents, доступ Read and write. GitHub сам добавит Metadata: Read-only. Остальные права не нужны.
  4. Срок действия — например, 90 дней. Скопируйте токен и сохраните в менеджере паролей.
  5. Если токен утёк, удалите его на той же странице GitHub — он сразу перестанет работать.
